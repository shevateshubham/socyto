SOCYTO — Architectural calm. The product should feel like an architect's portfolio evolved into a precise workspace: editorial hierarchy, structural grid, warm stone/ivory planes, deep olive primary, sage focus indicators, gold only for small milestone accents. Minimal but not sterile; a human, premium aesthetic that respects construction, documentation, and client trust.
Light-only for first iteration. Responsive mobile-first, with considered tablet widths and compact landscape. Spacious overview, tighter utilitarian forms. White paper cards against warm ivory canvas; fine olive-gray borders; softly rounded 16–22px modules; occasional raised olive hero. No gradient overload, emoji dashboards, or overly saturated UI.
Typography: 'DM Sans' for quiet UI and 'Newsreader' for editorial project titles and hero moments. Large titles breathe while data labels remain legible; tabular numerals for expenditures and progress.
Data must be trustworthy: sample fixtures ONLY in clearly labeled design preview. Production native Kotlin app has no fictional business records. Read-only clients never see private drafts, receipts or financials; publish requires an explicit action.
Accessibility: visible focus states, controls >=44px high, responsive grids and stack, no horizontal overflow, large text support. Native port should reproduce design tokens and interaction priorities, not copy React source verbatim.
