# Android Compose Skill
1. Inspect current Compose components and Gradle dependencies before editing.
2. Reuse existing Material 3 theme/tokens; follow DESIGN.md.
3. Support phones/tablets, font scaling, touch targets, semantic labels and responsive layouts.
4. Bind screens to actual state; include loading, empty, error, retry, offline and permissions states.
5. Never simulate live projects with hardcoded demo records or credentials.
6. Add appropriate UI/viewmodel tests and report whether they ran.
