# SOCYTO Android

Native Android app for SOCYTO interior project management.

## Version 0.1
- Kotlin + Jetpack Compose Android starter
- Admin project dashboard and local project creation
- Hybrid checklist/quantity progress calculations
- GitHub Actions debug APK builds

**Status:** Android starter; cloud authentication, client accounts, receipts and publication backend are planned, not yet deployed. Demo project data is not used as production data.

## Build
Open in Android Studio with JDK 17, or run the GitHub Actions **Android Debug APK** workflow. The APK is available as an Actions artifact after a successful run.

Never commit client data, API secrets, service-role keys, signing keys, or invoices to this public repository.
