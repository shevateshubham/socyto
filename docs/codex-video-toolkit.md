## Usage rule

These are **catalogued resources, not installed dependencies**. Some are Codex skills; others are MCP servers, websites, plugins, examples, commercial services, or library collections. Before adoption, verify license, setup, project relevance, trust/security and permissions. Do not auto-run third-party installers or expose secrets. Keep this catalog available as inspiration for future projects, even when a tool is currently unused.
